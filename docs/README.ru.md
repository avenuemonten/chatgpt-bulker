# ChatGPT Bulker

Расширение Chrome для выбора, удаления и архивирования чатов ChatGPT. Автор — [avenue](https://github.com/avenuemonten).

**[Скачать v1.0.0](https://github.com/avenuemonten/chatgpt-bulker/releases/latest)** · [English](../README.md)

## Скачать и установить

1. Откройте [Releases](https://github.com/avenuemonten/chatgpt-bulker/releases/latest).
2. В разделе **Assets** скачайте **`chatgpt-bulker-1.0.0.zip`**.
3. Распакуйте архив в постоянную папку на компьютере.
4. Откройте **`chrome://extensions/`**.
5. Включите **«Режим разработчика»** → **«Загрузить распакованное расширение»**.
6. Выберите папку, в которой лежит **`manifest.json`**.
7. Откройте [ChatGPT](https://chatgpt.com/) и обновите вкладку.

Оставьте включённой одну копию расширения. Чтобы закрепить иконку на панели Chrome, откройте меню расширений и нажмите значок закрепления.

## Как удалить только нужные чаты

1. Над списком чатов нажмите **«Выбрать»**.
2. Отметьте нужные чаты галочками. Нажимать **«Выбрать всё»** не требуется.
3. Выберите **«Удалить»** или **«Архивировать»** и подтвердите действие.

Удаление необратимо. Архивированные чаты остаются в аккаунте ChatGPT. При необходимости обработку можно остановить, а оставшуюся очередь продолжить позже.

## Окно расширения

Нажмите на иконку на панели Chrome: откроется инструкция, кнопка перехода в ChatGPT и ссылка на GitHub автора. Окно оформлено на английском; элементы выбора чатов используют язык интерфейса ChatGPT.

## Данные

Расширение отправляет выбранные действия непосредственно в ChatGPT через вашу текущую сессию. Настройки и очередь хранятся в Chrome. Сервера разработчика и телеметрии нет.
